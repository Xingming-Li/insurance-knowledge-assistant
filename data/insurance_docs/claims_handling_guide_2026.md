## 1. Så anmäler du en skada

1.1 Skadeanmälan kan göras på tre sätt:
- via **kundportalen** på webben,
- via **mobilappen** NordicPaws, eller
- med **pappersblankett** som skickas per post.

1.2 En skadeanmälan ska innehålla uppgifter om det försäkrade djuret, händelsen samt de handlingar som anges i avsnitt 3.

## 2. Tidsfrist för anmälan

2.1 En skada ska anmälas inom **12 månader** från behandlingsdatumet.

2.2 Anmälan som inkommer efter tidsfristen kan komma att avvisas.

## 3. Handlingar som krävs

3.1 Följande handlingar ska bifogas skadeanmälan:
- **Specificerad faktura** från kliniken där klinikens **organisationsnummer** framgår,
- **journalanteckningar/kliniska journaler** som beskriver undersökning och behandling,
- **betalningsbevis** som styrker att fakturan är betald,
- **remiss** vid specialistvård, där sådan är tillämplig,
- **händelsebeskrivning** vid olycksfall.

3.2 Ofullständig dokumentation kan förlänga handläggningstiden.

## 4. Direktreglering

4.1 Vid anslutna samarbetskliniker kan **direktreglering** tillämpas. Det innebär att NordicPaws Försäkring betalar den ersättningsbara delen direkt till kliniken.

4.2 Vid direktreglering betalar kunden endast sin självrisk och eventuell icke ersättningsbar del vid besökstillfället.

## 5. Handläggningstider

5.1 Standardärenden handläggs normalt inom **10 arbetsdagar** från det att fullständig dokumentation inkommit.

5.2 Komplexa ärenden kan ta upp till **30 arbetsdagar**.

## 6. Utbetalning

6.1 Ersättning betalas ut till försäkringstagarens angivna bankkonto, eller direkt till kliniken vid direktreglering (se avsnitt 4).

## 7. Överklagande

7.1 Ett beslut kan överklagas inom **30 dagar** från beslutsdatumet.

7.2 Överklaganden prövas av bolagets skadeprövningsnämnd (Skadeprövningsnämnden).

7.3 Instruktioner för hur ett överklagande lämnas in framgår av beslutsmeddelandet.
