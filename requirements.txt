# NordicPaws Insurance Knowledge Assistant — Dependency Set

# WHY THESE VERSIONS
# The base project (langchain-rag) pinned the langchain 0.2.x line, but
# the venv has langchain-core 1.4.3 installed alongside the old
# integration packages (e.g., langchain-openai 0.1.8).
# For this demo, I standardise on the langchain 0.3.x generation that
# supports LCEL and the modern langchain-chroma vector store.

# Recommended: install into a FRESH venv to avoid disturbing the old
# project's environment.
