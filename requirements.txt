# NordicPaws Insurance Knowledge Assistant — pinned dependency set.
#
# WHY THESE VERSIONS
# The reference project (langchain-rag) pinned the langchain 0.2.x line, but the
# shared environment now has langchain-core 1.x installed alongside the old
# integration packages (langchain-openai 0.1.8), which is internally broken
# (langchain-openai 0.1.8 imports the removed `langchain_core.pydantic_v1`).
# We standardise on the 0.3.x generation: a coherent, widely-used, stable set
# that supports LCEL and the modern `langchain-chroma` vector store, so we can
# drop the deprecated `model.predict()` and `db.persist()` calls.
#
# Recommended: install into a FRESH virtualenv to avoid disturbing the
# reference project's environment.
